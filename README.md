# バイオームマスター 🌍

世界のバイオーム（植物群系）と代表的な植物を、気温・降水量のグラフ上の位置と結びつけて覚えられる学習ゲームです。

**遊ぶ**: https://tyama11.github.io/biome-master/

---

## 2つの学習モード

ホーム画面上部のタブから、覚えたい内容に合わせて切り替えられます。

1. **🗺️ バイオーム名で覚える**
   - グラフ上のバイオーム名が隠された状態で、カードの名前と気温・降水量の位置を合わせます。
2. **🌱 植物名で覚える**
   - 代表的な植物カードを選んで、その植物が見られるバイオームの位置に配置します。

---

## 難易度の選び方

- **🔰 かんたん**
  - 環境のヒント・絵文字・色つきのカードで、位置関係をじっくり覚えられます。
- **🌿 ふつう**
  - ヒント・絵文字・色が消え、文字だけで判別するモードです。
  - **「ふつう」をクリアすると、秘密の「👹 おに」モードが解放されます！**（タブごとに解放）
- **👹 おに（60秒タイムアタック）**
  - 3枚のカードが常時並び、正解すると次の問題が無限に出題されます。
  - **ミス**: 残り時間 `-5秒`
  - 60秒間の正解数がベスト記録としてタブに表示されます。

---

## 操作方法

### マウス・タッチ操作
- 右側のカードをクリックして選び、グラフ上の当てはまる位置をクリックします（カードをグラフへドラッグ＆ドロップしても配置できます）。

### キーボード操作
- `Tab`：カードへ移動
- `Enter` / `Space`：カードを選択
- `Esc`：選択中のカードを解除
- `1` `2` `3`：**おにモード**で、番号に対応するカードを選択
